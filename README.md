## Cómo Ejecutarlo:
1. Clonar este repositorio.
2. Configurar MySQL y crear la BD con crm_db.sql.
3. Importar el proyecto en Elipse.
4. Ejecutar en Apache Tomcat.
5. Acceder a http://localhost:8080/crm-web.
